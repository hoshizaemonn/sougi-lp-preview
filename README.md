# 家族葬の光 LP

`LP実装仕様書_家族葬の光_20260727.md` に基づく、ビルド不要の静的LPです。

## GitHub Pagesモックアップについて

- このGitHub Pagesは、クライアントによるデザイン・構成・動作確認用の一時モックアップです。
- 最終本番環境はWordPressです。GitHub Pages公開後も本番公開扱いにはしません。
- P1〜P8はすべて仮値であり、実電話番号・実法人情報・確定価格は掲載しません。
- このモックアップURLをGoogle広告などの広告配信に使用しません。
- 本番ドメイン、GA4、Google広告タグには接続しません。
- 実データ確定後にWordPressへ移植し、本番用の設定と動作確認を別途行います。

## ローカル確認

このディレクトリで静的サーバーを起動し、ブラウザから確認します。

```bash
python3 -m http.server 8000
```

GitHub Pagesには確認用モックアップとして公開していますが、本番公開・広告配信・本番ドメインへの接続は未実施です。検証中は `meta robots=noindex` と `robots.txt` の `Disallow: /` を維持します。

## 仮画像

- `assets/img/placeholders/` 配下の画像は、クライアント確認用モックアップの仮画像です。
- FVはコピーと分離した家族葬ホールの仮写真、CTAは可読性を優先した控えめな装飾背景です。
- 相談・ご葬儀の流れ・斎場・FAQの画像は、実在の人物・斎場・サービス内容を示すものではありません。
- 画像は生成AIで制作したオリジナル素材をWebPへ最適化しています。第三者の写真素材やロゴは使用していません。
- 本番では権利確認済みの正式素材へ差し替えます。同じファイル名・縦横比で置き換えればHTML・CSSの変更は不要です。
- 使用中の仮画像は、家族葬ホール、花祭壇、木目と花の装飾、相談、ご安置室、斎場外観、FAQ、電話相談スタッフ、FV・CTA装飾背景です。同じ写真の使い回しはしていません。
- 下層画像は `loading="lazy"`、全画像は寸法指定済みです。FVのホール画像だけ `fetchpriority="high"` とし、LCPへの影響を抑えています。
